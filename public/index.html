交给本地助手
首次使用？下载安装助手

Windows 64 位：下载并解压完整文件夹，双击 install-helper.cmd 注册助手。保持文件夹位置不变。安装不需要管理员权限。

下载 Windows 助手

安装时从 Node.js 官网下载运行环境并校验。Git 克隆需要电脑已安装 Git；没有 Git 也可用助手下载 ZIP。卸载链接关联请运行 uninstall-helper.cmd。

若浏览器无法唤醒助手，下载项目清单，再在助手页面选择“导入网站项目清单”。

按「作者 / 仓库」分目录，已有项目自动跳过。

保留 .git 目录；取消勾选可下载完整提交历史。
